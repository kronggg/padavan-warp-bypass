# Changelog

Все значимые изменения в проекте будут задокументированы в этом файле.

## [3.8.1] - 2026-04-21

### Добавлено
- **Автоматическое определение параметров VPN-интерфейса.** Скрипт `ipset_update.sh` теперь сам определяет номер таблицы маршрутизации (`TABLE_ID`) и метку (`MARK_VALUE`) на основе текущей конфигурации. Это обеспечивает совместимость с различными сборками Padavan.

### Исправлено
- Заменён `grep -oP` на POSIX-совместимый `grep -oE` + `sed` для поддержки BusyBox.
- Улучшен алгоритм определения `TABLE_ID`: теперь правило ищется по наличию `fwmark` и `lookup`, а не по имени интерфейса.

## [3.8] - 2026-04-21

### Добавлено
- **Автообучение watchdog:** каждые 60 секунд анализируется `dmesg` на предмет неудачных SYN-пакетов к порту 443. IP-адреса назначения автоматически добавляются в `bypass_domains`. Позволяет открывать сайты, блокируемые провайдером путём сброса TCP-соединения (TCP Reset).
- Исправлено регулярное выражение для поиска записей в `dmesg`: теперь поддерживается любой порядок полей `DPT=443` и `SYN`.

### Изменено
- Увеличен интервал анализа автообучения до 60 секунд (переменная `ANALYZE_INTERVAL`).
- Обновлены комментарии и номер версии во всех скриптах.

## [3.7-beta] - 2026-04-19

### Добавлено
- **Поддержка IPv6:** создаётся отдельный ipset `bypass_domains6`, настраиваются `ip6tables` и policy routing для IPv6. Трафик IPv6 к сайтам из списков направляется через туннель WARP.
- **Правила CONNMARK:** добавлены правила `iptables` для сохранения метки `0xca6c` в conntrack и её восстановления для ответных пакетов. Улучшает стабильность соединений для сервисов, чувствительных к потере маршрута.
- **Автовосстановление ipset в watchdog:** если количество записей в `bypass_domains` падает ниже 100, watchdog автоматически запускает `ipset_update.sh`.
- Расширенные проверки в watchdog: добавлен контроль правил CONNMARK, ip6tables и IPv6 policy routing.

## [3.6] - 2026-04-17

### Добавлено
- Первая стабильная версия.
- Основной скрипт `ipset_update.sh` с поддержкой динамических списков `itdoginfo` и статических доменов.
- Настройка `dnsmasq` для мгновенного добавления IP при DNS-запросах.
- Policy routing (таблица 51, метка `0xca6c`) для направления трафика через `wg0`.
- Watchdog для восстановления правил `ip rule`, таблицы 51, `rp_filter` и `iptables MARK`.
- Ежедневный cron на 04:00.
- Автозагрузка с задержками.

## [3.5] и ранее
- Экспериментальные версии, не предназначенные для широкого использования.
