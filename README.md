# padavan-warp-bypass
Автоматическая система селективной маршрутизации для роутеров Padavan через AmneziaWG и Cloudflare WARP. Позволяет направлять трафик к избранным ресурсам через защищённый туннель, сохраняя прямой доступ к российским ресурсам.

# 🚀 Селективная маршрутизация через AmneziaWG + WARP на Padavan

**Автоматическая система, которая направляет трафик к выбранным сайтам через защищённый туннель Cloudflare WARP, сохраняя прямой доступ к российским ресурсам.**

## 📌 Что делает система

- **YouTube, Discord, Telegram, WhatsApp** и тысячи других сервисов работают быстро и стабильно через зашифрованный канал.
- **Отечественные сайты, банки, госуслуги** идут напрямую через вашего провайдера без потери скорости и с вашим реальным IP.
- **Полный автомат:** списки доменов обновляются ежедневно, IP добавляются "на лету" при обращении с любого устройства.
- **Встроенный сторож (watchdog):** если веб-интерфейс роутера сломает настройки после смены конфига WARP, система сама всё исправит за 15–30 секунд.

## 🛠️ Требования

- Роутер с прошивкой **Padavan** (ядро Linux 4.4 или новее).
- Настроенный и работающий VPN-клиент **AmneziaWG** с конфигурацией **Cloudflare WARP**.
- Включённый доступ по SSH.

## 📥 Установка (одной командой)

### Проверка доступности

Перед установкой убедитесь, что репозиторий доступен:

curl -I https://raw.githubusercontent.com/kronggg/padavan-warp-bypass/main/install.sh | head -1

Ожидаемый ответ: HTTP/2 200

Подключитесь к роутеру по SSH и выполните:

curl -sL https://raw.githubusercontent.com/kronggg/padavan-warp-bypass/main/install.sh | sh

## Альтернативный способ (ручная установка)
Если вы предпочитаете сначала изучить скрипт:

✅ Проверка работы

*Если какой-то сервис не открывается, подождите 20–30 секунд и обновите страницу.*

## ⚙️ Как это устроено
ipset хранит IP-адреса, трафик к которым нужно маркировать.

dnsmasq автоматически добавляет IP в ipset при DNS-запросах от устройств.
iptables маркирует пакеты меткой 0xca6c.
Policy routing направляет помеченные пакеты в отдельную таблицу 51, где маршрут по умолчанию ведёт в туннель wg0.
Cron каждую ночь в 04:00 скачивает свежие списки доменов и обновляет ipset.
Watchdog каждые 15 секунд проверяет целостность правил и восстанавливает их при необходимости.

## 🔧 Ручное добавление доменов (для тестирования)
Если вы хотите быстро добавить домен или IP в список маршрутизации:

sh /etc/storage/add_to_ipset.sh domen.com # Добавить IP

sh /etc/storage/del_from_ipset.sh <IP> # Удалить IP

## 🚫 Известные ограничения
Сервисы Meta (Instagram, Facebook, Threads) могут работать нестабильно или не работать вовсе. Это ограничение на стороне Cloudflare WARP, которое невозможно обойти настройками роутера.
Если вам критичны эти ресурсы, используйте отдельный VPN-клиент непосредственно на устройстве.
